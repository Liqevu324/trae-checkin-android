Trae 签到助手 v2.2.0 更新说明
（相较上一版 v2.1.2，versionCode 5 → 6，2026-11-10）
==================================================

一句话：把「网页版登录 + cookie 换 token」整条链路换成官方 SOLO OAuth，
让手机端拿到的凭证第一次具备桌面客户端的身份。

一、登录链路重做
--------------------------------------------------
- 登录页从网页版 /login 改为官方授权页 /authorization，
  回调地址为 http://127.0.0.1:18080/authorize。
- App 在 WebView 内截获回调，用 refreshToken 调 ExchangeToken 换长期凭证，
  不再依赖 cookie 换短期 JWT（旧路径保留给老账号兜底）。
- 全程在手机内完成，不需要电脑、不需要本地起服务。

二、设备号与请求契约对齐
--------------------------------------------------
- device_id 由 UUID / hex 改为 12~20 位纯数字，并随授权页一起注册；
  老账号已有设备号自动迁移，不丢账号。
- 签到请求体由 req_source=1 改为 req_source=2；
  补齐 X-Device-Id、X-User-Region: CN 请求头。

三、判定与错误处理
--------------------------------------------------
- 余额改为读服务端账本（usage_summary.total_amount - consumed_amount），
  与 Trae 客户端显示的可用额度一致。
- 新增「code=0 后回查 status.checked_in=true 才算成功」，
  避免 HTTP 200 但实际没发积分的假成功。
- 新增 9074 自动换设备号重试；9095 判定为「今日已签」终局；
  1001 自动用 refreshToken 续期一次。

四、安全
--------------------------------------------------
- 新增 network_security_config：仅对 127.0.0.1 放行明文，其余全部强制 HTTPS。

五、安装
--------------------------------------------------
- 覆盖安装即可，账号与日志保留（签名与旧版一致，未轮换密钥）。
- 从 2.1.x 升级后若提示登录过期，点账号菜单「重新登录」走一次新授权即可。
