# 兼容性说明

## 系统要求

- Android 7.0+（minSdk 24，targetSdk 34）。
- 推荐 Android System WebView / Chrome 84+；Chrome 83 有内置语法降级，但仍建议更新。
- 不需要 root、LSPosed、Xposed，也不需要电脑或本地服务器。

## 已验证范围

- Android 真机（1080×2340）验证：添加账号、登录回跳、一键签到、定时签到、通知、账号导入 / 导出。
- 仓库不逐条声明具体机型与 ROM 的测试结果；下面「国产 ROM 设置」是通用路径，实际名称以系统为准。
- 如果你在某机型上遇到问题，欢迎在 Issues 中附：版本号、Android 版本、ROM、错误码与日志。

## 国产 ROM 后台设置

| ROM | 自启动 / 后台 | 电池优化 | 备注 |
|---|---|---|---|
| ColorOS / OPPO | 设置 → 应用 → 自启动 / 关联启动 | 电池 → 更多 → 睡眠待机优化 → 允许后台 | 同时允许通知 |
| OriginOS / vivo | i 管家 → 应用管理 → 自启动 | 电池 → 后台耗电管理 → 允许 | 建议锁定后台 |
| HyperOS / MIUI | 设置 → 应用设置 → 授权管理 → 自启动 | 电池 → 无限制 | 建议锁定后台 |
| EMUI / HarmonyOS | 手机管家 → 应用启动管理 → 手动管理 | 电池 → 更多 → 睡眠待机优化 | 允许自启动 / 关联启动 |
| 原生 Android | 设置 → 应用 → 电池 → 无限制 | 电池优化 → 不优化 | 允许后台运行 |

> 不同系统版本的菜单名称可能不同；找不到时在设置里搜索「自启动」「电池优化」「后台运行」。

## WebView

- 登录页是 React 应用，官方 JS 使用 ES2022 语法（私有方法、`??=`），需要 Chrome 84+。
- App 对 Chrome 83 的 `8049.*.js` 做只读语法降级；但降级器只适配当前前端构建，官方换用新语法时可能失效。
- 遇到「页面能看能输入、按钮点不动」或「网页脚本未能运行」：先更新 Android System WebView / Chrome，再重启 App。
- 仍不行时，长按「重新发起登录」复制诊断信息（含 `js_patch` 与报错位置）反馈。

## 网络

- 需要能访问 `api.trae.cn` 与 `www.trae.cn`；企业网络、代理、VPN、私人 DNS 可能拦截。
- App 不绕过 DNS 劫持 / 上游故障；某个网络长期解析失败时，换网络即可。
- 深度休眠（Doze）会限制后台网络；把 App 加入电池优化白名单可提高定时签到成功率。
