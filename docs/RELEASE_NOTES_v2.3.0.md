Trae 签到助手 v2.3.0 更新说明
（相较上一版 v2.2.0，versionCode 6 → 7，2026-11-10）
==================================================

一句话：攻下 9074。上一版虽然换成了 SOLO OAuth，但领取仍会被设备校验拒绝；
这一版把请求契约与设备号形态改对，纯手机端终于能真正领到 100 积分。

一、修复 9074（设备校验未通过）
--------------------------------------------------
- 移除 x-device-brand=Windows、x-os-version=10.0.22631 这两个自带矛盾的头：
  授权链接里声明的是 PC / 1.0，再补一套 Windows 指纹会被上游当成伪造设备，
  claim 稳定返回 9074（status 只读，所以查余额一直正常，只有领取失败）。
- 严格对齐官方客户端的最小请求头集合。
- machine_id 修正为独立的 32 位 hex（此前误设成与 device_id 相同）。

二、新增「设置设备号」
--------------------------------------------------
- 账号卡片菜单新增「设置设备号」：可手动填写 12~20 位纯数字设备号，
  也可粘贴桌面客户端 storage.json 的整段文本自动提取。
- 设备号带来源标记（手动 / 自动）：
  · 手动填的真机号绝不自动轮换；
  · 自动号 24 小时内最多换一次，避免每轮都换把唯一有效的号弄丢；
  · 「重新登录」不会覆盖手动设置的设备号。
- 保存时检测撞号（同一设备号签多个账号会回 9095）。

三、日志与兜底
--------------------------------------------------
- 长按日志复制新增 device_id、device_src、device_rotated、req_source 诊断字段（不含凭据）。
- 9074 / 9004 时仍然保存账号并标记失效，避免白登录一次。

四、安装
--------------------------------------------------
- 覆盖安装即可，账号、历史、设备号全部保留（签名未轮换）。
- 若仍报 9074：账号菜单 →「设置设备号」，填一次电脑版 TRAE 的设备号。
