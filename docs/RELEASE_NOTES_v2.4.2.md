# Trae 签到助手 v2.4.2

> 本次是「合规与文档修订版」：登录、签到、9074 处理、定时、日志等核心逻辑未改，手机上几乎感觉不到差别。

## 更新内容（APK）

### 本次变更

- **版本号**：`2.4.1` → `2.4.2`，`versionCode 9` → `10`
- **用户协议**：删除与 MIT 冲突的「禁止商用」条款，改为「MIT 允许商业使用，但未授权收费售卖或官方背书」；删除「绕过官方风控」等自我定性，改为「是否属于平台允许的使用方式，请以官方条款为准」
- **使用说明书**：删除「从桌面客户端 `storage.json` 提取设备号」的逐步教程，只保留「手动指定 12~20 位纯数字设备标识」；「100 积分」改为「额度以官方为准」；「模拟手动操作」改为「避免固定时间集中请求」
- **隐私协议**：修正「不收集、不存储」这类绝对化表述；补充剪贴板导入 / 导出的风险提示（Android 13+ 会显示预览，导出后请及时清空）
- **开源许可页**：补齐三个参考项目的许可证标注（Maquer=MIT、xiaoyinge=未声明、cowpy=GPL-3.0），并说明未复制其源码
- **设置设备号功能保留**：这是纯手机端通过 9074 校验的关键，没有删除

### 没有变的部分

- 登录、签到、`9074 / 9095 / 9004 / 1001` 处理、凭证刷新、定时调度、签到日志、界面布局、配色、动画、图标全部未改
- 20 个 Java 类的业务代码未改；`classes.dex` 的字符串差异只有版本号 `2.4.1 → 2.4.2`
- 本次 APK 共 81 个文件，其中 72 个与 v2.4.1 二进制完全一致；变化的 9 个文件为：
  `AndroidManifest.xml`、`classes.dex`、`res/raw/doc_guide.txt`、`doc_terms.txt`、`doc_privacy.txt`、`doc_opensource.txt`、`META-INF/MANIFEST.MF`、`TRAE.SF`、`TRAE.RSA`

## 安装

- 从本 Release 的 **Assets** 下载 `TraeCheckin-2.4.2.apk`，传到手机安装；要求 **Android 7.0+（minSdk 24）**
- **可直接覆盖安装 v2.4.1 / 2.4.0 / 2.3.0 / 2.2.0**：签名证书一致，账号、签到记录、手动设置的设备号、设置项全部保留，无需卸载、无需重新登录
- 从源码自行构建、且未提供原签名私钥的版本签名不同，需先卸载旧版（会清空本地数据）

## 升级建议

- 如果你已经装了 v2.4.1 且使用正常，**不升级也完全可以**；升级的主要意义是拿到修正后的协议文案。
