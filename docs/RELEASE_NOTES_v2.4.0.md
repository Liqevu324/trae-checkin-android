Trae 签到助手 v2.4.0 更新说明
（相较上一版 v2.3.0，versionCode 7 → 8，2026-11-10）
==================================================

一句话：功能与界面大版本 —— 设置页按原版重构成 5 个分组，
补齐凭证保活、排除账号、导入导出、内置文档与关于区。

一、设置页重构
--------------------------------------------------
- 按分组重排：自动任务 / 签到配置 / 后台与权限 / 数据 / 帮助与协议，
  补齐分组标题、卡片分隔线、蓝色数值链接与淡紫 Tab 选中胶囊。

二、新增功能
--------------------------------------------------
- 每日自动凭证保活：每天 03:30 自动换一次登录凭证，独立开关，
  避免到点签到时 token 已过期。
- 积分到期提醒：每天首次打开检查权益包到期与余额，7 天内到期或余额偏低时提示。
  （后续版本已按用户要求移除该功能。）
- 管理签到时间与排除账号：可改签到时间，并多选不参与自动签到的账号；
  被排除账号不参与一键签到 / 首开签到 / 定时签到 / 凭证保活，卡片上会标注。
- 账号导入 / 导出（JSON）：导出前给出凭据安全提示；导入自动预填剪贴板，
  按 token / uid 去重且只追加不覆盖。
- 四份内置中文文档：使用说明书、隐私协议、用户协议与免责声明、开源许可与致谢
  （原生 Spannable 渲染，不需要 WebView）。
- 关于区：作者卡片、开发者、版本号、MIT 许可证与页脚免责声明。

三、界面
--------------------------------------------------
- 全局 Activity 转场（240ms 淡入 + 轻微位移）、页面内容浮入、Tab 胶囊缩放淡入。
- 配色对齐原版采样：主色 #2F6BFF、背景 #F5F6FB、描述 #6C757C、选中胶囊 #E8DEF7。

四、安装
--------------------------------------------------
- 覆盖安装，账号与日志保留。新增设置项默认值不影响既有行为。
