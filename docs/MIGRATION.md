# 迁移与备份

> 账号、签到日志、设置都保存在应用私有目录；**卸载会全部清除**。换机、刷机、卸载前请先导出账号。

## 导出账号

1. 打开 App → 设置 → 数据 → 导出账号（JSON）。
2. 复制 JSON，粘贴到安全位置（本地加密笔记、私密文件）；不要发到公开群、公开网盘或仓库。
3. 导出的 JSON 等同于账号登录状态，包含 `token` / `refreshToken`；泄露等于账号可能被接管。

## 导入账号

1. 新设备安装同版本或更高版本（推荐 v2.4.3）。
2. 设置 → 数据 → 导入账号（JSON），粘贴 JSON。
3. 导入只追加、不覆盖；按 token / uid 去重。
4. 导入后如提示 `9074` / `1001` / `9004`，按 [排障手册](TROUBLESHOOTING.md) 处理；必要时重新登录。

## 设备号

- **2.4.4 起**：重新登录会原样沿用旧 `device_id` 与 `machine_id`，无论旧号是手动还是自动；只有新账号才生成新号。
- 成功领取过一次后，当前设备号会被标记为 `device_id_verified`；之后遇到 `9074` 不会自动换号，避免把唯一能用的绑定换掉。
- 「设置设备号」手动填写的 12~20 位纯数字会标记为 `manual`；`9074` 时不会自动轮换，重新登录也不会覆盖。
- 未验证的新号遇到 `9074`，24 小时内最多自动换一次；仍失败时手动设置。
- 一个设备号一天只能签一个账号；多账号请分别使用不同号码。
- `9095` 通常表示该设备号今天已经签过，换号或确认账号状态。

> 2.4.3 及更早版本重新登录会重新生成自动号，可能导致原本能签到的账号变成 `9074`。
> 如果已经中招：填入重新登录前的旧设备号，保存为手动号，再重新登录一次。

## 换机步骤

1. **旧机**：设置 → 数据 → 导出账号；记下手动设置的设备号（如有）。
2. **新机**：安装 v2.4.3 或更高版本；导入 JSON。
3. 逐个账号检查：能签到则完成；如 `9074`，设置设备号或重新登录。
4. 确认新机正常后，再处理旧机；**不要先卸载旧机**。

## 升级与降级

- 2.2.0 → 2.4.3 可直接覆盖安装，账号、签到记录、手动设备号与设置保留；6 个 APK 使用同一签名证书。
- **不建议降级**：Android 会拒绝 `versionCode` 更低的包；卸载后降级会清空本地数据。
- 从 2.1.x 及更早版本升级：每个账号重新登录一次（旧授权链接的设备指纹与当前契约不一致，容易 `9074`）。
- 从其他签名版本升级：必须先卸载（会清空数据），卸载前先导出。

## 日志与备份

- 签到日志**不随**账号 JSON 导出；需要保留时截图或长按复制。
- 清除日志不可恢复。
- 更多问题见 [排障手册](TROUBLESHOOTING.md)；系统后台设置见 [兼容性说明](COMPATIBILITY.md)。
