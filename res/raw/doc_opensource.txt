## 6. 构建方式

本仓库不含 Gradle 工程文件，使用 build.sh 直接调用 Android SDK 构建工具：

- aapt2 compile / link
- javac --release 8
- d8
- zip 塞入 classes.dex
- zipalign
- apksigner sign / verify

依赖 JDK 17+、Android SDK build-tools 34.0.0 与 platforms android-34。
仓库不含 APK 签名私钥。build.sh 的签名凭据通过 SIGNING_KEYSTORE /
SIGNING_STORE_PASS / SIGNING_KEY_PASS 等环境变量提供，脚本内不含任何口令；
未配置时仅生成一次性调试密钥，产物不可用于发布或覆盖安装官方 Release 版本。

## 7. 参与贡献

欢迎通过开源仓库提交 Issue 与 Pull Request。提交前请确认：

- 不引入任何第三方依赖，保持零 Gradle、纯原生实现
- 不提交 keystore、token、cookie 或任何真实账号数据
- 新增功能需附带中文说明与对应的设置项文案
- 提交前运行 bash build.sh 验证可构建
- 参考或引入第三方代码 / 文案 / 图片时，同步更新 THIRD-PARTY-NOTICES.md

## 8. 反馈

问题反馈请附上机型、Android 版本、应用版本与长按日志复制出的完整报错。
日志输出不含登录凭据，可安全用于公开反馈。请勿在公开渠道粘贴 token、
refreshToken、cookie 或 storage.json 完整内容。
